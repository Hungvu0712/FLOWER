# 🌸 Dự án Hoa Xinh — Trang thông tin

Xin chào! Đây là nơi đội phát triển cập nhật **tiến độ, đề xuất, rủi ro và ước lượng** của dự án
website bán hoa **Hoa Xinh**.

Trang này được cập nhật **hai tuần một lần** (hoặc ngay khi có thay đổi quan trọng), tự động đồng bộ
từ mã nguồn nên thông tin luôn khớp với thực tế công việc.
